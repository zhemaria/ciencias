Cladograma Interactivo

Explora cómo los cladogramas representan relaciones evolutivas entre organismos.

🎯 Objetivo de aprendizaje

Al completar esta actividad, podrás identificar las partes principales de un cladograma y explicar cómo se usan para representar relaciones evolutivas.

📚 Vocabulario clave

Cladograma: diagrama que muestra hipótesis sobre relaciones evolutivas.
Clado: grupo formado por un ancestro común y todos sus descendientes.
Nodo: punto donde un linaje se divide en dos ramas.
Sinapomorfia: rasgo derivado compartido que ayuda a definir un clado.

📝 Instrucciones

  1. Haz clic en cada botón para explorar una parte del cladograma.
  2. Observa qué elemento se resalta en el diagrama.
  3. Lee la explicación que aparece debajo del cladograma.
  4. Compara los organismos para identificar cuáles están más relacionados.
  5. Contesta las preguntas de reflexión al final.

Nota de accesibilidad: puedes usar la tecla Tab para moverte entre los botones y Enter o la barra espaciadora para seleccionarlos. En pantallas pequeñas, puedes desplazar el diagrama horizontalmente.

🎮 Cladograma interactivo

Si estás usando un teléfono, desliza horizontalmente para ver todo el cladograma.

🔍 Selecciona un elemento

Haz clic en cualquiera de los botones de arriba para aprender sobre las diferentes partes de un cladograma.

💭 Preguntas de reflexión

  1. ¿Qué representa la raíz de un cladograma?
  2. ¿Por qué los nodos son importantes para entender la evolución?
  3. ¿Qué diferencia hay entre un clado y una rama?
  4. ¿Cómo ayuda un grupo externo a interpretar las relaciones evolutivas?
  5. Observa el cladograma: ¿qué organismos parecen estar más relacionados entre sí? Explica tu respuesta usando el diagrama.
